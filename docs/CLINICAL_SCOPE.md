# 處置與術前討論功能的實作範圍

本版將分析結果、資料缺漏、來源及專業人員備註整理成 Heart Team 討論準備清單。它記錄人員是否已覆核相關資料，並保留來源版本。所有勾選完成只會得到 `ready_for_mdt`，意思是可安排多專業討論；它不代表手術適應症成立、手術風險已評估完成、已取得知情同意，或手術已獲核准。

## 實際可操作流程

1. 完成本次影像分析，確認來源、類型、模型或規則來源，以及是否為合成資料。
2. 由授權人員逐項確認急性狀態、冠狀動脈解剖、症狀與缺血、左心室功能、風險與共病、病人偏好及既有治療資料。旗標只接受是、否或未知；系統不從候選數或網格自動填寫。
3. 有急性警訊時優先顯示院所急症處理提示，停止一般方案清單。資料未知或未覆核時列出待補項目。
4. 檢視三種教育性討論類別：既有治療與追蹤、PCI、CABG。類別不排序、不推薦到此個案、不產生處方或醫囑。
5. 專業人員可記錄自己的討論備註；原文標示為人工輸入，與 AI 模型摘要分開保存。系統不以語言模型改寫成手術建議。
6. 最後的處置選擇，應由合格團隊依完整證據與病人共同決策；本機軟體的覆核紀錄不是醫院正式授權或電子簽章。

## 影像與 3D 證據界線

候選定位顯示的是偵測工具的位置與信心輸出；它不自動證明血管狹窄、血流限制或缺血。零候選也不排除疾病。本版的少量 MRI 研究切片未完成心功能或冠狀動脈病變測量。

閾值分割與體素邊界網格讓使用者核對幾何處理流程。即使 DICOM 間距與方向已核對，這種表面仍未經解剖標註、分割效能、器械誤差或手術導航驗證。它不是冠狀動脈手術規劃、切割路徑或導航模型。合成體模的 Dice、體積或網格一致性只代表軟體幾何驗證。

本版不計算 STS、SYNTAX 或 EuroSCORE，不由年齡、候選框、LLM 或 3D 形狀推定風險或治療適應症。正式模型、專業工作流程及院內治理仍須各自驗證。

## 軟體驗證

`tests/test_discussion.py` 驗證未知／否旗標、急性優先、嚴格型別、人工備註來源、合成及 MRI 證據限制，以及所有旗標齊備仍不產生手術建議。這些是工作流程測試，不是臨床決策效度驗證。
